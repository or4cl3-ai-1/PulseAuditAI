# PulseAudit Evolution Roadmap

## Strategic Directions (All Active)

### 1. Sovereign Engine — Enterprise Trust Plane
**Target:** Large-scale Fintech + Healthcare requiring data sovereignty  
**Core Features:**
- Self-hosted log mode (sensitive audit trails stay in client VPC)
- Regulatory Traceability Graph visualization
- Secondary data egress prevention

### 2. Transparency Protocol — AI BOM Integration
**Target:** EU AI Act compliance (August 2, 2026 deadline)  
**Core Features:**
- AI Bill of Materials generator (machine-readable inventory)
- Model + dataset lineage tracking
- Automated Article 50 transparency documentation

### 3. Developer Nexus — Compliance-as-Code
**Target:** DevOps + Engineering teams (shift-left compliance)  
**Core Features:**
- PulseAudit SDK (Node.js, Python, Go)
- CLI for CI/CD integration
- Compliance checks as unit tests
- Pre-commit hooks + GitHub Actions workflows

## Implementation Plan

**Phase 1 (Week 1):** Sovereign Engine backend + UI
**Phase 2 (Week 2):** AI BOM module + EU AI Act templates
**Phase 3 (Week 3):** SDK + CLI + docs
**Phase 4 (Week 4):** Integration testing + launch

All three ship together as PulseAudit 2.0.
